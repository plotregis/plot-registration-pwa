PUBLISH THIS FOLDER'S CONTENTS TO THE ROOT OF AN HTTPS STATIC HOST.
1. Set the deployed Apps Script /exec URL in config.js.
2. Upload index.html, config.js, sw.js, manifest.webmanifest, .nojekyll and icons/ to your GitHub Pages repository root.
3. Enable GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root).
4. Open the published HTTPS URL in Chrome and choose Install app.
Do not upload Apps Script source, credentials, Script Properties or registration data to the public static host.
See ../README.txt for the complete deployment and security checklist.
