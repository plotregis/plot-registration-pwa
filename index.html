Plot Registration Support

Connecting securely to your registration system…

Setup is required. Add your deployed Google Apps Script web app URL ending in /exec to config.js, then publish the PWA site again.

The installed app requires an internet connection for login, records and file uploads.

Install Plot Registration Support

In Chrome, open the three-dot menu and choose Install app or Add to Home screen, then confirm installation.

If the app does not open inside the installed window, test the Apps Script URL directly in Chrome first and complete any Google authorization.
